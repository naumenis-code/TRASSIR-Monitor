TRASSIR Monitor
```big
Полноценный веб‑дашборд для мониторинга серверов TRASSIR с определением имён отключённых каналов, алертами и графиками.
Работает на Debian 11/12/13.
```

🚀 Возможности
```big
Live‑дашборд — состояние всех серверов обновляется через WebSocket в реальном времени.
Точные имена отключённых каналов — система запрашивает GUID каждого канала и определяет, есть ли сигнал (не просто число офлайн‑камер).
Алерты — автоматическое уведомление о проблемах:
Отказ дисков
Отвал камер (с именами)
Высокая загрузка CPU
Малая глубина архива
Алерты не дублируются — одно событие = один алерт, до подтверждения.
Графики — динамика CPU, числа онлайн‑камер и глубины архива за 6 ч / 24 ч / 7 дн.
Детальная страница сервера — все метрики, история, алерты, время ответа, uptime.
Поддержка SSL/TLS — работа с самоподписанными сертификатами TRASSIR.
Мультисерверность — неограниченное количество серверов в едином интерфейсе.
Управление серверами — добавление, редактирование, удаление через GUI.
Настройка порогов — гибкая конфигурация критических значений CPU и архива.
Московское время (UTC+3) — все записи в локальном времени.
Простое удаление — специальный скрипт, который не трогает системные пакеты.
```
📦 Требования
```big
ОС: Debian 11 / 12 / 13 (чистая установка или уже используемый сервер)
Права root (для установки)
Серверы TRASSIR с включённым веб-сервером и заполненным SDK‑паролем
Свободный порт для веб-интерфейса (по умолчанию 8080)
Интернет для скачивания пакетов (только во время установки)
Скрипт автоматически установит Python 3, виртуальное окружение, Nginx и все зависимости.
```
🔧 Настройка и добавление серверов
```big
1. Получение SDK‑пароля в TRASSIR
На каждом сервере TRASSIR, который вы хотите мониторить:
Откройте Настройки → Веб‑сервер → Общие.
Скопируйте или задайте Пароль SDK.
2. Добавление сервера в мониторинг
Нажмите кнопку «+ Добавить сервер» (в правом верхнем углу или плавающая кнопка).
Заполните поля:
Название — любое удобное имя.
IP адрес — адрес сервера TRASSIR.
Порт — обычно 8080.
Тип авторизации — выберите SDK Пароль.
SDK Пароль — вставьте пароль из настроек TRASSIR.
SSL — если используется HTTPS (по умолчанию да).
Нажмите «Проверить подключение», чтобы убедиться в доступности.
После успешного теста нажмите «Добавить сервер».
Через несколько секунд дашборд обновится и покажет состояние нового сервера.
```

Клик по имени сервера открывает детальную страницу.
Детальная страница сервера
Карточки метрик — CPU, камеры, диски, архив, uptime, отклик — обновляются каждые 30 секунд.
Интерактивный график — кнопки 6ч/24ч/7д переключают масштаб.
Список алертов — все предупреждения и ошибки, отсортированные по времени. Кнопка «Сбросить все» подтверждает алерты.

🚨 Алерты
```big
Система автоматически создаёт алерты при обнаружении проблем.
Алерт появляется только если ещё нет активного (неподтверждённого) с таким же текстом для этого сервера.

Уровень	Триггер
🔴 Critical	Ошибка дисков (disks = 0)
🟡 Warning	Отвал камер (с именами), высокая загрузка CPU, маленькая глубина архива
Пример алерта при отвале камер:

Камер офлайн (2): Камера 1, Камера 5
Если каналов много, отображаются первые пять с указанием количества оставшихся.

Алерты можно сбросить кнопкой «Сбросить все» на странице сервера.
```
📈 Графики и история
```big
На детальной странице сервера доступен комбинированный график с тремя шкалами:
CPU % (левая шкала, фиолетовый)
Камеры онлайн (правая шкала, зелёный)
Архив, дни (вспомогательная скрытая шкала, жёлтый)
Данные автоматически подгружаются за выбранный период: 6 часов, 24 часа или 7 дней. Все записи хранятся в локальной SQLite‑базе.
```
⚙ Управление и обслуживание
```big
Основные команды
bash
# Статус сервиса
systemctl status trassir-monitor

# Просмотр логов приложения
journalctl -u trassir-monitor -f

# Лог сбора данных (отключённые каналы и т.п.)
tail -f /opt/trassir-monitor/logs/collect.log
Ручной перезапуск
bash
systemctl restart trassir-monitor
Система автоматически запускается при старте сервера и перезапускается при сбоях.

🗑 Удаление
Используйте встроенный безопасный деинсталлятор:

bash
sudo trassir-monitor-uninstall
Он удалит только файлы проекта, не затрагивая:

Установленные системные пакеты (Python, Nginx и т.д.)

Другие проекты на сервере

Пользовательские данные (по желанию можно сохранить базу)

При выполнении потребуется ввести DELETE заглавными буквами для подтверждения, а также будет предложено сохранить резервную копию базы данных.
```
❓ Часто задаваемые вопросы
```big
Где взять SDK‑пароль?
В веб‑интерфейсе TRASSIR:
Настройки → Веб‑сервер → Общие → Пароль SDK.
Если поле пустое – задайте любой пароль и сохраните.

Почему имена отключённых каналов не отображаются сразу?
При первом опросе после добавления сервера или после перезапуска может потребоваться несколько циклов.
Имена запрашиваются только если channels_online < channels_total. Для большого числа каналов запрос выполняется последовательно, что может занять несколько секунд.

Как изменить порт веб-интерфейса после установки?
Отредактируйте файл /etc/nginx/sites-available/trassir-monitor, изменив listen на нужный порт, затем выполните:

bash
systemctl reload nginx
Можно ли мониторить серверы без SSL?
Да, при добавлении сервера снимите галочку «Использовать SSL». Убедитесь, что на сервере TRASSIR веб‑сервер настроен на HTTP.
```
