## ✨ Возможности

| Функция | Описание |
|---|---|
| 🔴 **Live-дашборд** | Состояние всех серверов обновляется через WebSocket в реальном времени |
| 📷 **Имена отключённых камер** | Система запрашивает GUID каждого канала — вы видите конкретные имена, а не просто число |
| 🚨 **Алерты без дублей** | Одно событие = один алерт, до явного подтверждения |
| 📈 **Графики истории** | CPU, камеры онлайн, глубина архива — за 6 ч / 24 ч / 7 дн |
| 🖥 **Детальная страница** | Все метрики, история, алерты, uptime и время отклика по каждому серверу |
| 🔒 **SSL/TLS** | Поддержка самоподписанных сертификатов TRASSIR |
| 🌐 **Мультисерверность** | Неограниченное количество серверов в едином интерфейсе |
| ⚙️ **Гибкие пороги** | Настройка критических значений CPU и глубины архива |
| 🕒 **Московское время** | Все записи сохраняются в UTC+3 |
| 🤖 **Telegram-бот** | Опциональные уведомления в Telegram (устанавливается отдельно) |
| 🗑 **Чистое удаление** | Деинсталлятор удаляет только проект, системные пакеты остаются |

## 📦 Требования

- **ОС:** Debian 11, 12 или 13
- **Права:** `root` (для установки)
- **На серверах TRASSIR:** включённый веб-сервер + заполненный SDK‑пароль
- **Порт:** 8080 свободен (или любой другой — настраивается)
- **Интернет:** только во время установки (скачивание пакетов)

> ℹ️ Python 3, виртуальное окружение, Nginx и все зависимости устанавливаются **автоматически**.

## 🚀 Быстрая установка

```bash
wget https://raw.githubusercontent.com/naumenis-code/TRASSIR-Monitor/main/install-trassir-monitor.sh
sudo bash install-trassir-monitor.sh
```

Скрипт установки сделает всё сам:
- установит Python 3, Nginx и необходимые библиотеки
- создаст виртуальное окружение в `/opt/trassir-monitor/`
- настроит systemd-сервис с автозапуском
- выведет адрес веб-интерфейса

После установки дашборд доступен по адресу:
```
http://<IP-сервера>:8080/
```

## 🔌 Добавление серверов TRASSIR

### Шаг 1 — Найдите SDK‑пароль на сервере TRASSIR

```
TRASSIR → Настройки → Веб‑сервер → Общие → Пароль SDK
```
Если поле пустое — задайте любой пароль и сохраните.

### Шаг 2 — Добавьте сервер в дашборд

1. Нажмите **«+ Добавить сервер»** (кнопка в правом верхнем углу)
2. Заполните форму:

| Поле | Пример | Описание |
|---|---|---|
| Название | `Офис Москва` | Любое удобное имя |
| IP адрес | `192.168.1.100` | IP сервера TRASSIR |
| Порт | `8080` | Порт веб-сервера TRASSIR |
| Тип авторизации | `SDK Пароль` | — |
| SDK Пароль | `mypassword123` | Из настроек TRASSIR |
| SSL | ✅ включён | Если сервер использует HTTPS |

3. Нажмите **«Проверить подключение»**
4. Нажмите **«Добавить сервер»**

## 🖥️ Веб-интерфейс

### Главный дашборд `/`
- **Сводная строка** — серверов, камер онлайн/офлайн, активных алертов
- **Карточки серверов** с цветовым индикатором: 🟢 норма / 🟡 предупреждение / 🔴 критично
- Клик по имени сервера → детальная страница

### Детальная страница `/server/<id>`
- Карточки метрик обновляются каждые 30 с
- Интерактивный график: `6 ч` / `24 ч` / `7 дн`
- Список алертов + кнопка **«Сбросить все»**

### Настройки `/settings`
- Интервал опроса серверов
- Глубина хранения истории (в днях)
- Пороги алертов — CPU и архив (Warning / Critical)
- Управление серверами

## 🚨 Алерты

**Повторный алерт с тем же текстом не создаётся**, пока предыдущий не подтверждён.

| Уровень | Условие срабатывания |
|---|---|
| 🔴 **Critical** | Ошибка дисков (`disks = 0`) |
| 🟡 **Warning** | Камеры офлайн, высокий CPU, маленькая глубина архива |

**Пример алерта:**
```
Камер офлайн (3): Камера 1, Камера 5, Вход_северный
```

## 📈 Графики и история

| Метрика | Цвет | Шкала |
|---|---|---|
| CPU % | 🟣 фиолетовый | левая |
| Камеры онлайн | 🟢 зелёный | правая |
| Архив (дни) | 🟡 жёлтый | вспомогательная |

Данные хранятся в локальной SQLite‑базе (`/opt/trassir-monitor/trassir.db`).

## 🤖 Telegram-уведомления

Опциональный модуль, устанавливается отдельно поверх основной системы.

### Установка

```bash
wget https://raw.githubusercontent.com/naumenis-code/TRASSIR-Monitor/main/install-telegram-notifier.sh
sudo bash install-telegram-notifier.sh
```

Потребуется: **Bot Token** (от [@BotFather](https://t.me/BotFather)) и **Chat ID**.

### Удаление бота (без затрагивания основной системы)

```bash
wget https://raw.githubusercontent.com/naumenis-code/TRASSIR-Monitor/main/uninstall-telegram-bot.sh
sudo bash uninstall-telegram-bot.sh
```

> ✅ База данных и все данные мониторинга при этом сохраняются. Перед удалением создаётся резервная копия.

## ⚙️ Управление сервисом

```bash
# Статус
systemctl status trassir-monitor

# Перезапуск
systemctl restart trassir-monitor

# Логи в реальном времени
journalctl -u trassir-monitor -f

# Лог сбора данных
tail -f /opt/trassir-monitor/logs/collect.log

# Логи Telegram-бота
tail -f /opt/trassir-monitor/logs/tgbot.log
```

---

## 🗑️ Удаление

```bash
sudo trassir-monitor-uninstall
```

Потребуется ввести `DELETE` заглавными буквами. Предложит сохранить резервную копию базы данных.

**Удаляется:** файлы проекта, конфиг Nginx, systemd-сервис.  
**НЕ удаляется:** Python, Nginx, другие сервисы на сервере.

## ❓ FAQ

<details>
<summary><b>Где взять SDK-пароль?</b></summary>

**Настройки → Веб‑сервер → Общие → Пароль SDK** на сервере TRASSIR.  
Если поле пустое — задайте любой пароль и сохраните.
</details>

<details>
<summary><b>Почему имена камер не отображаются сразу?</b></summary>

Имена запрашиваются только при `channels_online < channels_total`. При первом опросе или после перезапуска может потребоваться несколько циклов.
</details>

<details>
<summary><b>Как изменить порт после установки?</b></summary>

```bash
nano /etc/nginx/sites-available/trassir-monitor
# Изменить значение listen
systemctl reload nginx
```
</details>

<details>
<summary><b>Можно ли работать без SSL?</b></summary>

Да. При добавлении сервера снимите галочку **«Использовать SSL»** и убедитесь, что TRASSIR настроен на HTTP.
</details>

<details>
<summary><b>Можно ли установить рядом с другими сервисами?</b></summary>

Да. Создаётся изолированное окружение Python и отдельный Nginx‑сайт. Убедитесь только, что выбранный порт свободен.
</details>

<details>
<summary><b>Как восстановить Telegram-бота?</b></summary>

```bash
sudo bash install-telegram-notifier.sh
```

Или из бэкапа:
```bash
cp /opt/trassir-monitor/backups/telegram-<дата>/app.py.bak /opt/trassir-monitor/app/app.py
```
</details>
